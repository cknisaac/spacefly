## Scientific identity

- Describe the primary model as a **connectome-constrained spiking simulation** or a **biologically motivated Drosophila neural simulation**. Never call it a literal or complete fly-brain emulation without independent validation.
- Keep observed connectome facts, experimental evidence, inferred annotations, biological hypotheses, and engineering choices distinct in code, configuration, documentation, and reports. Maintain `ASSUMPTIONS.md` and, when implemented, `docs/BIOLOGY.md` and `docs/MODEL.md` with sources, units, uncertainties, and sensitivity tests.
- The imported connectome determines the primary network's internal topology. Keep it immutable and provenance-tracked. Label every artificial sensory injection, reward route, motor attachment, lesion, and topology edit as an overlay; never present an overlay as a measured fly synapse.
- Do not assume anatomical connectivity proves function. Do not infer synaptic sign solely from a transmitter label when receptor or effect is unknown. Preserve unknowns and report their coverage.
- For Circuit V1, read `docs/CIRCUIT_V1_EFFECT_POLICY.md` and its pinned policy manifest before electrical work. An unmatched connection remains `UNKNOWN` with no default positive weight. APL's local graded state and the DANs' modulatory state must not be silently converted to ordinary LIF synapses. New numeric effects, delays, neuron constants or boundary drives require an explicit literature, inference or engineering provenance record. The historical Session 7 all-positive profile is not a parameter prior and must not be tuned into a pass.
- A synthetic network is a simulator and learning-system validation fixture, not evidence of fly-circuit learning.

## Primary experiment constraints

- Every modeled neuron has explicit temporal state. Communication uses timestamped spikes/events, or a separately named and justified biologically motivated approximation. Do not call a rate activation a spike.
- Learning in the primary experiment occurs only at an explicit, biologically motivated plastic-edge mask within selected fly circuitry. Use local eligibility and a declared neuromodulatory rule. Do not send reward or gradients directly into arbitrary synapses.
- Route game judgement through utility, reward expectation/error, an artificial reinforcement interface, selected DAN/modulatory populations, and eligibility-gated plasticity. Distinguish each stage in logs.
- Keep the primary motor mapping fixed and deterministic. No trainable MLP or linear decoder; no backpropagation, BPTT, PPO, or Adam on biological synapses. Conventional ML belongs in a clearly named baseline with separate results.
- Never expose the target key, ideal press time, future judgement, or held-out test answers through sensory encoding. The historical synthetic time-to-contact encoder uses exact future note time and must not be the MVP input. The MVP uses a fixed deterministic representation of **current visible note position only**, potentially injected into selected KCs; it cannot access exact future note timestamp, countdown or desired action time.
- Keep game judgement, hit value, score, accuracy, utility, action cost, and dopamine signal separate. Timing shaping is off by default and labelled when used. A null press is not an osu MISS.
- Make experiments capable of failing. Do not discard bad seeds, tune against held-out test maps, or claim topology-specific benefit without matched topology controls.

## Architecture and timing

- Use one deterministic integer-microsecond event timeline for beatmap objects, spikes, synaptic arrivals, key transitions, judgements, and reinforcement. Neural integration step is configurable and its quantization effects must be measured. Never determine judgements from accumulated floating-point frame deltas.
- Preserve stable source neuron IDs and provenance while mapping to contiguous runtime indices. Store topology in sparse outgoing adjacency and keep neuron state, edge state, plasticity state, and scheduler state separate. Never introduce a dense N×N matrix in the primary path.
- Specify event ordering, tie handling, minimum delay policy, and checkpoint/replay semantics before implementation. Any backend optimization must pass the same model-level tests and disclose numerical differences.
- Keep the osu environment, neural simulator, sensory/motor adapters, learning rules, orchestration, and analysis independently testable. Keep units explicit in names and interfaces.

## Evidence and reproducibility

- Every run must save resolved configuration, seed, code revision if available, connectome source/version/checksum, annotation and overlay manifests, ruleset version, and metrics definitions. Do not commit large generated connectome files; use manifests and checksums.
- Run deterministic CPU regression tests. Treat GPU nondeterminism as a documented limitation. Record raw per-event results and selective neural traces; do not default to recording every spike of a large network.
- Before fly training, pass the relevant judgement, neuron, synapse, plasticity, checkpoint, first-action and seed-reproducibility tests under the active A/B roadmaps. The historical synthetic M2 performance gate is not a prerequisite for Branch B.
- Predefine primary comparisons, seed policy, held-out splits, outcome metrics, and decision thresholds before final experiments. Evaluate generalization with plasticity off.
- Detect numerical failure, pathological activity, weight saturation, continuous presses, and unbounded event queues; save diagnostics instead of silently continuing.
