## Sequencing decision

The specification lists M3 connectome ingestion before M7 plasticity and M8 reinforcement, but its implementation pass requires a synthetic network to **learn the single-lane task before connectome ingestion**. To make both requirements possible, M2 includes a minimal synthetic learning integration gate using explicit local eligibility, utility/RPE, artificial reinforcement, and fixed sensory/motor adapters. M7 and M8 later validate and localize those mechanisms in an identified fly subcircuit. M2 success is an engineering gate, never the primary biological result. The user explicitly authorized the MaleCNS v1.0 import and later a non-learning staged scale profile while M2 remains failed. Those requests do not waive the learning gate for fly training or establish an identified, stable M4 task circuit.

## Cross-stage gates

- Before **any training**, pass every test named in the master specification's section 51: OD8 windows, positive/negative window symmetry where the actual ruleset is symmetric, boundaries, miss expiry, independent chord judgement, spike threshold, refractory period, excitatory/inhibitory synapses, delay, eligibility generation/decay, reward without eligibility, eligibility without reward, positive/negative modulation, weight bounds, checkpoint roundtrip, and seed reproducibility. - Before M2 and M9 learning claims, predeclare number of seeds, data splits, stopping rule, primary metric, improvement margin or inference rule, and uncertainty reporting. The master specification gives qualitative success criteria but no statistical threshold; inventing one after seeing results would bias conclusions.
- Preserve raw judgements and timing errors. Curves use training notes on the horizontal axis and include reward, hit/MAX/MAX+300 rates, misses, timing MAE, plastic changes and DAN/RPE activity. Report compute cost and failure seeds.
- Checkpoints and deterministic replay become acceptance requirements before resumable training or claimed reproduction. A checkpoint must capture neuron and eligible synapse state, reward baseline, curriculum/environment state, queue/RNG state, config and connectome checksum.
- Later **visual sensory input** and **long-note learning** need separate gates after the corresponding interface and game mechanics are validated; neither is silently included in M12. A Project A comparison is a separate future experiment, never a substitute for the primary controls.
