## Verification history and limits

The first manifest import failed on a Python line-break syntax error; fixing it exposed that allowed differences were declared at a parent field while the comparator reported leaf fields. The validator now generates and checks exact leaf paths. The first short fixture ran through **190,000 µs**, when the natural motor action for `n1` duplicated its synthetic feedback outcome. The bounded control probe now stops at **189,000 µs**, after PAM spikes and selected updates but before that natural action. The separate long wrong-note fixture uses a distinct synthetic origin ID so natural task feedback remains independent. These were implementation/fixture corrections, not evidence-driven parameter tuning.

Final review added a guard so wrong-note routing also skips a later onset if it carries the pulse's own origin ID. A targeted test and a new current-code [v2 receipt](figures/a4_matched_controls_v2/receipt.json) passed with the same declared counts. The first receipt under `docs/figures/a4_matched_controls/` remains as versioned process history; v2 is authoritative.

The 130 changed selected pairs show that the synthetic request exercised the local update path in this one matched state. They do not show controllability of the game action, effective learning, retention, or biological validity. Wrong-note routing, DAN suppression and eligibility blocking are **engineering control overlays**. In eligibility-disabled mode, preexisting traces at the parent cut remain stored but are neither used for updates nor incremented while the switch is active. Historical A2 checkpoints have an earlier source-tree identity and should be treated as version-pinned evidence; A4 saves a new parent under the current code.
