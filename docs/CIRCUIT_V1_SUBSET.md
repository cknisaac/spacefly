# MaleCNS Circuit V1 subset: reproducible data product

**Date:** 2026-09-29. **Scope:** exact anatomical extraction from the validated MaleCNS v1.0 official traced-only graph. [CIRCUIT_V1.md](../CIRCUIT_V1.md) explains the biological roles and unresolved physiology. This product assigns no synaptic sign, gain, delay, intrinsic dynamics, dopamine model or action rule.

## Selection and products

[`configs/circuit_v1_selection.json`](../configs/circuit_v1_selection.json) is the executable selection contract. It names the three candidate visual inputs, the complete right KCg-d class, APL, PPL101, the complete right PAM01(y5) cohort, five MBONs and left DNa03/DNa02. Each role has an anatomical selector and a reason for inclusion. Individual bodies are pinned by source ID plus type/instance checks; the two complete classes are pinned by their exact source-ID hashes and expected sizes. The 140-ID union is pinned by a separate SHA-256. No connection-weight ranking or filler neurons are used.

## Build and independent verification

From the project root in PowerShell, with the repository's `.venv` containing the optional `connectome` dependencies:

```powershell
$env:PYTHONPATH = 'src'
.\.venv\Scripts\python.exe -m scripts.build_circuit_v1
.\.venv\Scripts\python.exe -m scripts.audit_circuit_v1
.\.venv\Scripts\python.exe -m unittest tests.test_circuit_v1_subset -v
```

The builder refuses a parent that differs from its validated receipt or the pinned selection. It refuses missing IDs, type/member drift and overlapping roles. The independent audit reconstructs the role union and all induced edges from the parent, compares every selected annotation field and source edge, checks the candidate mask, and recomputes whole-circuit and per-role boundary counts. The saved `audit.json` reports **passed** for the current products.

A second production build produced **byte-identical** `manifest.json` and identical Parquet hashes. Four focused selector tests and the full **91-test** project suite passed. The first bare `python -m scripts.build_circuit_v1` invocation failed because this repository requires `PYTHONPATH=src`; the documented command above succeeded. No neural dynamics or training ran.
