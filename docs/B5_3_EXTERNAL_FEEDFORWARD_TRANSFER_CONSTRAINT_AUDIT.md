# B5.3 — external feedforward transfer-constraint audit

**2026-09-30. Research result: PASS as a discriminating evidence audit; FAIL to obtain a transferable numerical envelope for either exact MaleCNS stage.** The question and criteria were [predeclared after B5.2](B5_2_VISUAL_INPUT_BOUNDARY_AUDIT.md#one-proposed-next-stage-b53-not-run) before this targeted primary-literature review. No new neural model, current, threshold, delay, stimulus, simulation or task probe was made.

## What was sought

An independent numerical V1.1 transfer hypothesis would need a measured presynaptic protocol, identified postsynaptic subtype, current or voltage in stated units, response timing, and a defensible map from that measurement to the selected MaleCNS source-body/contact arrangement. It cannot be a value chosen because B5 did not spike. The [V1 engineering policy](ELECTRICAL_MODEL_V1.md) has `+0.03 pA/contact` on selected visual→KC, `+0.01 pA/contact` on KC→MBON32, 5-ms current decay, `KCg-d` C/g **5 pF/0.5 nS**, and MBON32 C/g **20 pF/1 nS**. These are model values, not measured synaptic efficacies.

**Visual→KC conclusion:** no reviewed primary result gives a per-EM-contact or per-spike transfer curve for the exact `aMe12_R`/current visual IDs onto the 107 selected MaleCNS `KCγ-d` bodies. The 5-ms V1 decay is not clearly absurd as a generic cholinergic timescale, and the V1 KC intrinsic surrogate may already be unusually small/high-resistance relative to broader γ-KC examples. Therefore raising visual per-contact current or lowering KC threshold using B5's diagnostic **7–534×** critical multipliers has no independent calibration. `UNKNOWN` exact transfer; `ENGINEERING ASSUMPTION` remains the current scale.

**KC→MBON32 conclusion:** class-level cholinergic excitation is supported, but neither collective γ-KC EPSCs onto a different MBON nor MBON-α3 passive measurements identify MBON32's exact efficacy, intrinsic firing onset, natural background drive or precise KC volley timing. B5.1's diagnostic **1.748×** critical multiplier is a local model sensitivity, not an external effect estimate. `UNKNOWN` exact transfer and missing-input state remain.

## Readiness decision

The predeclared criterion for a **new numerical** V1.1 hypothesis fails at both stages. The result is **not** that the V1 numbers are biologically validated; it is that reviewed measurements cannot be transferred at the required resolution. The [B5.2 exact source-ID audit](B5_2_VISUAL_INPUT_BOUNDARY_AUDIT.md) *does* permit a narrower, falsifiable V1.1 **boundary-only** design: add right `aMe12` IDs **12740/13190**, preserve every existing numeric V1 value, and mark their visual stimulation and positive KC effect as explicit inherited engineering/inference hypotheses. That design tests whether the documented omission matters under a frozen policy. It cannot be sold as a calibrated fix, and the known KC→MBON32 failure remains a separate gate. The bounded [V1.1 readiness contract](ELECTRICAL_MODEL_V1_1_READINESS.md) states the exact allowed change and controls.

**Next single stage proposed, not run:** B5.4, boundary-only V1.1 implementation and task-independent matched V1/V1.1 revalidation under a locked protocol. Do not choose a better gain, excite UNKNOWN edges, add a key readout, or train. Stop before that implementation stage.
