## Verification and limits

The focused A5 selection suite passed **2/2**. The complete regression run passed **153 of 154** tests in 56.575 seconds. Its sole failure was a historical Circuit V1 test comparing byte hashes of newly written Parquet files against files created by **pyarrow 21.0.0**; the available runtime has **pyarrow 25.0.1**. The only manifest differences were the two Parquet artifact hashes; the boundary JSON hash and all other manifest fields matched. This environment mismatch did not affect the A5 tests or replay checks. The first A5 evidence launch with system Python lacked `pyarrow`; the separate fly virtual environment lacked `yaml`. The successful runs used system Python with the fly environment's site-packages on `PYTHONPATH`.

The fixture horizon, seeds and frozen panel are deliberately small. A5 proves that all selected states can be captured, restored, replayed and inspected with the same frozen panel, including a result ledger that does not select by performance. Because no selected weight changed in these six source states, the policy-reset arm was a no-op in this fixture; A2 separately exercised fresh frozen evaluation using a controlled noninitial selected policy. The A5 panel does **not** demonstrate learned first-action timing, retained learning, controllability or a recurring biological mechanism. The candidate-specific training horizon and run set remain to be predeclared before actual B4 runs.
