# Branch B — connectome-constrained fly learning

**Main scientific branch after the 2026-10-01 methodology pivot.** The MVP asks whether a **model** built from measured MaleCNS connectivity, using a learning rule with relevant experimental support, learns when to make its **first** action from a fixed causal representation of current visible note position. Adaptive state must be within selected connectome-constrained fly synapses. The allowed chain is fixed position encoder → fly circuit with internal plasticity → fixed, non-trainable key interface. A frozen fly with a trained external decoder does not satisfy the primary claim.

At evaluation, plasticity and exploration are off; encoder and motor interface are exactly those used in training. Later presses cannot rescue the first-action metric. No fly-task learning experiment has started. The old B1–B5.6 visual work is preserved as the [deferred biological-fidelity track](DEFERRED_VISUAL_KC_TRACK.md).

## Fixed sensory contract

The MVP input is **current visible note position**, such as a present-frame spatial coordinate or lane-local position, mapped by a **fixed deterministic population representation** to the selected sensory boundary. The encoder may stimulate selected KCs directly. It must be auditable from the present observation alone and must have no access to exact future hit timestamp, exact time-to-contact countdown, desired press time, future note information or learned parameters. Log observations and emitted population drive so the information boundary can be checked. The precise geometry, tuning curves, visibility and KC IDs are B1/B2 decisions; this migration does not implement or calibrate them.

The existing [`TimeToContactEncoder`](../src/project_b/sensory/time_to_contact.py) accepts `note_time_us` and computes `note_time_us - time_us`; the synthetic runner supplies the exact unresolved note timestamp. It is therefore too informative for this MVP, even though it remains valid historical fixture code. Do not use it in a Branch B confirmation run. Electrical values without identifying biological measurements may be disclosed **ENGINEERING ASSUMPTIONS**, never measured physiology. The learning *rule* needs relevant experimental support, selected with its pathway at B1.
