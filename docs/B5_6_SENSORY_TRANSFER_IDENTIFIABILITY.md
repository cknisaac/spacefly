# B5.6 — independent visual→KC transfer identifiability gate

**2026-09-30 to 2026-10-01. Scientific gate: FAIL to identify a transferable joint numerical envelope. Evidence/provenance audit: PASS.** The [locked protocol](../configs/b5_6_sensory_transfer_identifiability.json) was saved before the focused search. This stage reviewed primary visual-pathway and KC physiology sources; it did not run a simulator, select a current or threshold, revise V1/V1.1, or test KC→MBON32.

## Question and acceptance rule

Can independent adult visual `KCγ-d` evidence jointly constrain **(i)** the effective input from a source class such as `aMe12` and **(ii)** KC intrinsic current-to-spike behavior, with units and uncertainty sufficient to state one falsifiable numerical sensory-entry hypothesis for the selected MaleCNS cells? The rule requires source-attributed stimulation or spikes and postsynaptic current/voltage, plus subtype-matched excitability or a justified linked current-to-spike relation. EM contacts, natural light-evoked KC responses and model spike thresholds cannot individually meet it.

The fixed MaleCNS v1.0 anatomy is `MEASURED`: the five selected right visual bodies **13285/13707/13874/12740/13190** directly contact **79/107** selected right `KCγ-d` cells, including 20 added by V1.1 ([B5.2](B5_2_VISUAL_INPUT_BOUNDARY_AUDIT.md)). This says who can contact whom, not pA per contact. V1/V1.1 `+0.03 pA/contact`, 5-ms current decay and KC **5 pF/0.5 nS** are `ENGINEERING ASSUMPTION`, not measured for these bodies. B5.5's median **24.25×** critical effective-drive multiplier is a model sensitivity and is **excluded from parameter selection**.

## Interpretation and status

The `MEASURED` contact graph and `LITERATURE-CONSTRAINED` visual activity make the route plausible. They do **not** identify an electrical number for the selected source-body-to-KC mapping. The strongest B5.6 evidence adds a useful `INFERRED` conclusion: visual drive can reach `aMe12` and `γd` activity in adult preparations, while its exact gain in the reduced MaleCNS surrogate remains `UNKNOWN`. The remaining missing terms are:

1. Source-attributed `aMe12` stimulation or spike-locked postsynaptic current/voltage in identified adult `γd` KCs, preferably with pair/contact attribution and release variability.
2. Matched `γd` current-step passive properties and spike onset/rheobase, or a validated linked current-to-spike response for the same preparation.
3. Physiological source timing, co-input and inhibitory context needed to map those measurements to the five-body reduced boundary.

Thus B5.6 **fails its independent numerical identifiability gate**. V1.1 still fails KC recruitment; B5 complete sensory→DN and M4 route validation remain blocked. The direct KC→MBON32 deficit is separate and unchanged. No V1.2 gain, altered threshold, event-timing policy or source substitution is authorized by this evidence.

The [independent structural/provenance audit](figures/b5_6_sensory_transfer_identifiability/audit.json) passed **14 checks** over five primary-source ledger rows, all pinned V1/V1.1/B5.3/B5.5 hashes, source uniqueness, criteria completeness, decision consistency and the anatomy/physiology distinction. It does not machine-verify the contents of external papers. The audit first failed because the pre-search protocol contained a one-character transcription error in the pinned B5.5 audit SHA-256; the actual saved B5.5 file was unchanged. Only that hash string was corrected, the audit reran and passed. No scientific acceptance criterion changed. The full project regression suite passed **115 tests** under the repository `.venv`.
